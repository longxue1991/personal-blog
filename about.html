ABOUT THIS DESK曹雪龙

一张留给
长期问题的工作台。

代码工作台是一个个人札记站。它保存算法训练中的判断、竞赛数据里的变化，以及那些值得反复修改的想法。

PROFILE / 01

学习、训练，
也把过程留下来。

关注信息学竞赛、算法实现与数据表达。写作时会尽量区分事实、口径和推断，让后来复查的人可以顺着线索走回去。

这个站点使用纯 HTML、CSS 和 JavaScript 构建，由 GitHub Pages 发布，没有后台，也没有追踪脚本。
